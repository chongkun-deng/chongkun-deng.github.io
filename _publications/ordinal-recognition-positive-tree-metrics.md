**Status:** Work in progress  
**Author:** Chongkun Deng

Can the structure of a weighted tree be recovered when numerical distances are unavailable and only relative comparisons are observed? This project studies that recognition problem under the assumption that every tree vertex is labeled.

I develop a polynomial-time construction that identifies the tree topology through ordinal relative-neighborhood relations, including an \(O(n^2)\) topology-recovery phase. A sparse linear program then determines whether positive edge weights can realize all observed rankings and provides concise certificates when realization is impossible. The project also examines which parts of the method extend from trees to general weighted graphs.
